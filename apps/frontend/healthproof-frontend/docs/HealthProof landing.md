# <a name="_hmyy4agfifp7"></a>**5. HOW HEALTHPROOF WORKS**
### <a name="_154k2t2mv73"></a>**Headline**
**Verification without exposing medical data**
### <a name="_aknrrl89vxww"></a>**Workflow**
1️⃣ **Medical order issued**

A doctor creates a medical test order inside their system.

A cryptographic hash of the document is registered on blockchain.

-----
2️⃣ **Patient authorizes laboratory access**

The patient grants the laboratory permission to view the order.

Authorization can occur via QR code or one-click approval.

-----
3️⃣ **Laboratory performs the test**

The laboratory updates the exam status and uploads the results.

The new document is linked to the original order.

-----
4️⃣ **Doctor verifies results**

The patient returns to the medical center.

The doctor verifies the results instantly through HealthProof.

-----
### <a name="_2amp7wt8r17r"></a>**Key principle**
The patient does not share data.

**The patient shares permissions.**
